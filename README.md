# AR_Planets
A 2D endless runner game made in Unity 6. Jump over obstacles, beat your saved high score, and play against a scrolling parallax background.
## Planets AR v1.0.0

First release of Planets AR, an Android augmented reality guide to the solar system.

### What's included
- `Planets AR.apk`: ready-to-install Android app
- `Assets/`, `Packages/` and `ProjectSettings/`: the full Unity project files

### Features
- Home screen with buttons for all eight planets
- Textured 3D planets, with Saturn shown with its rings
- Live AR view through your phone's camera
- Rotating planets, placed in front of you when a scene opens
- Back button on every planet screen

### Requirements
- Android 7.0 (API 24) or higher
- A phone that supports ARCore
- Camera permission

### Install the APK
1. Download and extract the zip.
2. Copy `Planets AR.apk` to your phone and install it, allowing unknown sources if asked.
3. Open the app, allow camera access, and tap a planet.

### Open in Unity
1. Extract the zip into a new folder.
2. Add it in Unity Hub and open it with Unity 6000.0.85f2.
3. Open `Assets/Scenes/HomeScreen`.

### Notes
- AR can't be fully tested in the Unity editor, so test on a real device.
- Planet sizes and speeds are simplified and not to scale.
